# Migrator CLI

Кросспроектный CLI для версионирования схемы БД: применяет, откатывает и показывает состояние изменений схемы в чужих проектах, привязываясь к ним только через конфиг.

## Language

**Migration**:
Файл с парой обратимых операций `up`/`down`, имя которого начинается с временной метки и задаёт порядок применения.
_Avoid_: скрипт, ченджсет, версия

**Seeder**:
Migration, наполняющая базу данными, а не меняющая схему. Отличается от Migration только своим Namespace и папкой.
_Avoid_: фикстура, сид-скрипт

**Namespace**:
Независимая последовательность Migration со своей папкой и своим срезом Journal. Их ровно два: `migrations` и `seeders`.
_Avoid_: набор, коллекция, тип миграции

**Run**:
Одно исполнение команды, применяющей или откатывающей Migration. Слово «миграция» никогда не означает запуск.
_Avoid_: миграция (как процесс), прогон, сессия

**Config**:
Файл в проекте-потребителе, описывающий, к какой базе и к каким папкам привязан CLI. Единственное, что связывает инструмент с конкретным проектом.
_Avoid_: настройки, конфигурация, опции

**Journal**:
Таблица, в которой записано, какие Migration применены, когда и с каким Checksum. Единственный источник истины о состоянии базы.
_Avoid_: история, лог миграций, meta-таблица

**Executed**:
Состояние Migration, для которой есть запись в Journal.

**Pending**:
Состояние Migration, у которой есть файл, но нет записи в Journal.

**Missing**:
Состояние записи в Journal, для которой файла на диске больше нет. Блокирует откат и не мешает применению.
_Avoid_: осиротевшая, потерянная

**Drift**:
Расхождение Checksum между файлом Migration и записью в Journal: файл изменили после применения.
_Avoid_: рассинхрон, конфликт

**Checksum**:
sha256 сырых байт файла Migration, записанный в Journal в момент применения.

**Lock**:
Взаимное исключение, не позволяющее двум Run работать с одной базой одновременно.
_Avoid_: мьютекс, семафор
